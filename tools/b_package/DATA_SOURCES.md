# Data sources

Every corpus is read as data: programs as text, circuits by Qiskit's loaders. Nothing downloaded is executed.
Licence texts are in `data/LICENSES/` and beside each corpus. `python fetch_data.py --verify` checks every shipped
file against `MANIFEST.sha256.tsv`, and every QASMBench file against `data/qasmbench_files.sha256.tsv`.

## Shipped in `data/`

| Folder | Source | Licence | Used by |
|---|---|---|---|
| `mqtbench/` | 78 circuits exported from MQT Bench (https://github.com/cda-tum/mqt-bench), generator at commit `a10a74b` | MIT | OpenQASM 2 checks (RQ1) |
| `veriqbench/` | 966 circuits of VeriQBench (https://github.com/Veri-Q/Benchmark), byte-identical to upstream from commit `dc2651c` on | MIT | OpenQASM 2 checks; its OpenQASM 3 files in the OpenQASM 3 checks |
| `openqasm3_examples/` | the official examples, https://github.com/openqasm/openqasm at commit `7fbf9e9`, `examples/` | Apache-2.0 | OpenQASM 3 checks |
| `openqasm3_grammar/` | the official grammar and its test suite, same commit, `source/grammar/` | Apache-2.0 | OpenQASM 3 grammar checks |
| `openqasm3_roundtrip/` | `index.csv` and `ours/`: our programs exported by Qiskit's OpenQASM 3 exporter, with their answers. `corpus/` is regenerated by `experiments/icpc/oq3_export_corpus.py` from the OpenQASM 2 corpora | ours | OpenQASM 3 round trip |
| `bugs4q_ported/` | the Bugs4Q bugs' circuits, ported by hand from the buggy programs, with each instruction mapped to its source line (`PROVENANCE.txt`) | as Bugs4Q | RQ1 T1 and T2 |
| `lintq_artifact/` | LintQ's inspection CSVs and SARIF warnings, https://github.com/sola-st/LintQ at the commit in `COMMIT` | MIT | RQ4 comparison with LintQ |
