\section{Conclusion}\label{sec:conclusion}

We defined quantum dependence and slice soundness by the semantics of quantum programs and measured
dependence definitions against them. A slice is correct only if it follows data, control and quantum
dependence, so the classical PDG gives wrong slices for \numCpdgUnsoundPct{} of the pairs, while
entanglement edges cost precision without adding soundness and state-based pruning holds for one input
only. The QDG is sound, dependence-complete and cheap, and our static slicer applies it to Qiskit source,
with forward slices and qubit profiles from the same graph.

\section*{Data Availability}
The replication package at \url{https://anonymous.4open.science/r/qslice-replication-5B21} contains the protocol and its
deviations, the Isabelle/HOL theory of Theorem~\ref{thm:sound}, the static slicer, the benchmark circuits, the logs of every run with the commit it used, and
the scripts that regenerate every number, table and figure in this paper. Every random draw has a fixed
seed. The runs used Python~3.12.2 and Qiskit~2.3.0 on an Intel Xeon W-2140B workstation, with every
package version pinned in a lock file, and the package will be archived with a DOI on acceptance.
