\section{Conclusion}\label{sec:conclusion}

A quantum slice supports comprehension only if it keeps every operation that can change the state of the
qubits the developer asks about, a requirement we defined semantically and measured dependence rules
against. Reading the control of a gate as unchanged gives wrong
slices that can look right, and entanglement edges add code that cannot matter. The QDG is sound for every
input, dependence-complete and cheap, and our static slicer shows it on Qiskit source as the lines,
iterations and qubit profiles a developer reads, and a study with developers is the next step.
