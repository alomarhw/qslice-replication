\title{Static Program Slicing for Quantum Programs}
\author{\IEEEauthorblockN{Anonymous Author(s)}}
\maketitle

\begin{abstract}
Quantum programs are increasingly developed in general-purpose languages, particularly Python, using libraries such as
Qiskit to construct quantum circuits. Yet tools that help developers understand and debug these programs remain
limited. Program slicing identifies the statements that can affect a value of interest, but applying it to quantum
software requires tracking dependencies through gates and measurements, together with the classical computations that
determine which operations act on which qubits. In this paper, we extend the srcML infrastructure and the srcSlice slicer with a quantum layer that identifies the
quantum role of each API call, reconstructs the circuit a program builds without executing it, and slices every qubit,
including loops that run on the quantum device. Each slice identifies relevant source lines, the loop iterations that contribute circuit operations, and
the classical statements that determine those operations. We implement the approach in a tool, \tool{}, and
evaluate it on GitHub programs, Bugs4Q, the Qiskit textbook, Qiskit HumanEval and QASMBench. The reconstructed circuits
match those Qiskit builds, and the slices match reference slices on \numToolDevSliceEqual{} of \numToolDevPrograms{}
programs, where \tool{} is the more precise on the remaining one. The classical statements are complete for
\numSsContainPct{} of qubits, and for \numSsHeldContainPct{} in programs not used during development. \tool{} slices
\numScaleSOneSliced{} of \numScaleSOneFiles{} GitHub programs in a median of \numScaleSOneMedianMs{}~ms each and a
circuit of \numScaleQbMaxOps{} operations in \numScaleQbAllS{}~s, and a median slice holds \numScaleReadMedianPct{} of a
program's code lines. These results show that static slicing can support the comprehension of quantum programs,
pointing developers to the statements, loop iterations and classical computations that explain a qubit's state.
\end{abstract}
