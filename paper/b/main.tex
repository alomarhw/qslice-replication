\title{Static Program Slicing for Quantum Programming Languages}
\author{\IEEEauthorblockN{Anonymous Author(s)}}
\maketitle

\begin{abstract}
Quantum programs are increasingly written in general-purpose languages, most often in Python with Qiskit, where loops,
functions and computed indices decide which gates act on which qubits. While classical programs are supported by
mature slicing tools, quantum programs have almost none, and developers still debug them by printing, drawing
circuits and reading code. This work brings static program slicing to quantum programming languages. The srcML
infrastructure and the srcSlice slicer are extended with a quantum layer that identifies the quantum role of each
call, traces the circuit a program builds without executing it, and slices every qubit along the gates and measured
bits that can affect it. The approach is implemented in a tool, \tool{}, which reports a slice as source lines, the
loop iterations that put them in it, and the classical statements that compute them. \tool{} is evaluated on Qiskit
programs from GitHub (\numScaleSOneFiles{}), Bugs4Q, the Qiskit textbook and Qiskit HumanEval, and on OpenQASM
benchmarks of up to \numScaleQbMaxOps{} operations. It slices a typical program in milliseconds, and a qubit's slice
holds about a quarter of a program's code, giving developers a focused view of the statements that determine a qubit.
\end{abstract}
