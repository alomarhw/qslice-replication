# figures/

Each figure is generated by the script next to it. `../reproduce.sh` regenerates them all into `out/`.

| Figure | Script | Source |
|---|---|---|
| Fig. 1: typed QPDG of teleportation (UED/ED/MD/CD) | `fig1_qpdg_teleportation.py` | runs the four-edge implementation (`../fouredge/src`) on the circuit; also checks that its 17 edges match the edge set of the submitted Fig. 1 |
| Fig. 2: edge-type ablation | `fig2_ablation_rerun.py` | `../experiments/results/rq4_ablation/TAB_ablation_rerun.csv` |
| Fig. 3: scalability | `fig3_scalability.py` | `../experiments/results/rq5_scalability/`; also prints the pre-registered summary statistics |
| Fig. 4: Isabelle results | `fig4_isabelle.py` | parses `../isabelle/QSliceSoundness.thy` and runs `isabelle build` |
| Fig. 5: hardware TVD per circuit | `../hardware/scripts/recompute_hardware_tvd.py` | the captured IBM jobs in `../hardware/data/` |
